# Migração do servidor local

O backend de contas foi migrado para Supabase para permitir que o painel e os usuários se conectem pela internet, em computadores e redes diferentes.

Siga [SUPABASE-SETUP.md](./SUPABASE-SETUP.md) para criar o projeto online, publicar a API, configurar o build e distribuir os instaladores. O servidor local antigo não é mais incluído no painel.
